# Day Preview

See [[Calendar Providers]], [[Google Calendar]], [[Outlook Calendar]], and [[code-notes]].

The Settings arrows select an in-memory civil date; Today clears it. The display window keeps the same wall-clock times in the Calendar timezone, including 24-hour and overnight ranges.

Non-Today dates navigate the active provider when needed. Events stay empty while navigation settles and remain unavailable after a bounded failure. Preview mode disables reminders and automatic magnifier actions; undated Tasks remain Today-only.

Provider adapters own host-specific controls and mounted-date evidence. Outlook changes Work Week to Day only when the selected date is a weekend that Work Week cannot represent.
